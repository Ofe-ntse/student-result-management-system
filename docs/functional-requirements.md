# Functional Requirements
01.User Login- The system must allow users to log in using their username and password.
02.Login Validation- The system must check whether the username and password entered by the user are correct. If the details are incorrect, the system should display an error message.
03.Add Student- The administrator must be able to add a new student to the system. The student's information should be saved in the database.
04.Update Student - The administrator must be able to update existing student information when changes are needed.
05.Delete Student- The administrator must be able to delete a student record from the system.
06.Search Student- The system must allow users to search for a student using the student's ID. The student's information should then be displayed.
07.Manage Subjects- The system should allow subjects to be managed and stored in the database.
08.Display Subjects- The system should be able to display the subjects available for students.
09.Capture Results- The teacher should be able to enter student assessment marks into the system.
10. Update Results- The teacher should be able to update marks when a correction or change is needed.
11.View Results- The system should allow student results to be viewed. Students should only be able to view their own academic information.
12.Calculate Total Marks- The system should calculate the total marks for a student's results.
13.Calculate Average- The system should calculate the student's average based on their results.
14.Determine Pass or Fail- The system should determine whether a student has passed or failed based on their marks.
15.Display Reports- The system should display student results and performance information in the reports section.
16.Validate Information- The system should check information entered by users before it is saved. This helps prevent incorrect information from being entered into the database.
17.Display Error Messages- The system should display an error message when something goes wrong, such as incorrect login details or a database problem.
18.Database Connection- The application must be able to connect to the MySQL database so that information can be stored and retrieved.
19.Test Database Connection- The system includes a test connection function that can be used to check whether the application can connect to the database.
20.Audit Information- The system includes an audit log section for keeping track of information related to system activity.
